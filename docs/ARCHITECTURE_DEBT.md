# AngeVoice 架构债务台账

本文件是架构债务状态的唯一登记入口，描述当前源码的职责边界和剩余限制，不代表某个发行包已经包含全部改动。发行范围以对应 Git tag 和发布说明为准。设计说明见 [架构说明](ARCHITECTURE.md)，验证入口见 [测试指南](TESTING.md)，兼容移除条件见 [兼容层台账](COMPATIBILITY_LEDGER.md)。

## 状态与历史映射

状态核对日期：2026-09-22。**已闭合**仅指条目声明的行为边界；**部分完成**表示仍有具体残余；**持续治理**需要随依赖、使用方或部署环境重新评估。通过替身测试不等于真实模型、音质或所有硬件通过。

旧技术债务报告的 P1/P2/P3/P4/P4.5/P5/P6/P7 分别对应配置、worker、ZipVoice、MOSS、Kokoro、Manager、WS、路由；P0 为验证与治理。后续文本准备也曾使用 P5 编号，二者不同。以下稳定 AV-D ID 用于跨版本追踪。

## 更新规则

- 关闭条目必须说明行为边界、兼容、验证入口和剩余限制；不以文件数、类数或通过用例数代替完成标准。
- 先复核当前调用链与合同，再决定是否修改。新增抽象必须有明确职责与真实消费方，避免拆出共同修改同一状态的服务。
- 复杂度按 quality 门禁只降不升；覆盖率下限为 70%，同时检查变更路径与同环境基线。
- 验证命令、退出码、候选哈希、补丁和原始日志保存在独立审计产物；仓库保留可重跑的测试和稳定设计说明。
- 历史实现通过 Git 历史追溯，发行与真实模型结论绑定具体版本和环境，不能继承为后续候选的验收结果。
